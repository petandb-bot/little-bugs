# LITTLE BUGS v1.1.4 — Balance Polish

A tiny voice-mutation toy for your browser.

## Use

1. Tap **REC**, speak or sing, then **STOP** (up to 12 seconds).
2. Tap **HATCH** to create a Bug and a mutated loop. Hatch again for a different result.
3. Tap **PLAY** to listen. Toggle **GROOVE** for toy-synth accompaniment.
4. Tap **SAVE** to export a WAV file.
5. Tap an egg to change its shell, or tap a Bug to surprise it.

## What's changed

Smoother, level-matched bitcrushing helps prevent sudden loudness jumps. The ECHO identity now varies between rhythmic echo and shorter, cleaner tempo-synced delays. All six identities, existing synth grooves, eggs, Bugs, controls, and sound recipes are retained.

## GitHub Pages

Upload the **unzipped contents** to your repository root. Set **Settings → Pages → Deploy from a branch → main → /(root)**. The app runs over HTTPS.

Audio stays on your device. Please verify microphone access and WAV sharing on iPhone Safari.
